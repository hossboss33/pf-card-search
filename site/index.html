What this index holds

The parts of a cut card

  • Tag the debater's one-sentence claim
  • Cite short cite spoken in round, full cite below it
  • Underlined the sentences judged relevant
  • Highlighted the exact words read aloud
  • Minimized kept for context, not meant to be read

Reading view hides minimized text, the runs kept for evidence ethics rather than for reading.

Recent seasons

The search index on this site covers 2017-18 through 2022-23. Those seasons come from a public, MIT-licensed research dataset.

Seasons from 2023-24 onward exist only on openCaselist, which requires a Tabroom account to read any disclosure at all. That is their rule. If you have an account, your browser can read those seasons directly.

Connect to openCaselist

Read this before you type anything.

  • This form sends your Tabroom username and password directly to openCaselist (api.opencaselist.com) and nowhere else.
  • This site is static. It has no server, no backend, and no database of its own. It never receives, sees, or stores your login, and there is nowhere for it to be sent.
  • Your password is never written to storage of any kind. It is read from this form, put in one request, and dropped.
  • openCaselist requires a Tabroom account to read any disclosure. That requirement is theirs, not this site's.
  • Every line of this page is public and auditable: opencaselist.js.
  • If you would rather not type a password into a page you did not write, run the tool locally instead — see the README.

Requests are sent one at a time, at most one per second, because openCaselist is run by volunteers.

About this index

What it is

A search index over Public Forum evidence that teams disclosed publicly on openCaselist. Cards are grouped so that one row is one canonical card: the same excerpt disclosed by twenty teams is one result, with the read counts shown next to it.

There is no server. Your browser downloads only the parts of a prebuilt SQLite file that your query actually touches, using HTTP range requests, so searching does not require pulling the whole corpus.

Index contents

Rights in the card text

The body of every card is a quotation from a third-party publication. That text is not ours and is not covered by this project's license; it belongs to the publishers and authors named in each cite. Tags, cites and markup are the work of the debaters who cut and disclosed the cards. Everything here is reproduced for research and study of the public disclosure record, in the form the debaters themselves published it. Cites are never restamped: each card keeps the attribution its original cutter gave it.

If you are a rights holder and want a passage removed, open an issue on the repository and it will be taken out of the next build.
