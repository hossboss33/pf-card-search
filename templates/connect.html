What happens to what you type here

  • The username and password are POSTed over HTTPS straight to {{ api_base }}/login, which is openCaselist's own login route. Nothing else receives them.
  • They are held in memory in this server process, and nowhere else, so a long sync can re-authenticate when its openCaselist session lapses. They are never written to disk, never put in the database, never placed in a URL, never written to a log line, and never sent back to this page.
  • The session cookie openCaselist returns is kept in the same memory-only place.
  • Disconnect clears both immediately. So does stopping the server.
  • This page runs on localhost only. It refuses to answer on any other address, because it takes a password.
